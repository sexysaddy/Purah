# PURAH 1.4.2 — конфигурация и установщик

## Исправления

- `ensure_config.py` теперь дописывает недостающие `[browser]`, `[editor]`, `[memory]`, `[ui]` и `[terminal].visible_terminal_restore_focus` в существующий конфиг, включая частично заполненные секции. Настройки пользователя не меняются; миграция идемпотентна и создаёт резервную копию.
- Добавлен `doctor.py`, который без модификаций и доступа к API-ключам проверяет установленные компоненты, выбранный TTS, Vosk, CLI/AT-SPI, LSP и доступность портов Firefox BiDi / Chromium CDP.
- Новая команда `./install.sh --check` делает проверку без `sudo` и сетевой установки; отсутствующие обязательные компоненты дают код 1.
- Команда `./install.sh --with-telegram` устанавливает опциональные Telethon/cryptg. После авторизации `telegram.env` установщик восстанавливает пакеты при следующих обновлениях.
- `install.sh` проверяет версию Python >=3.11. Исправлена проверка системных утилит для дистрибутивов без `pacman`: ydotool не требуется при выключенном резервном управлении мышью.
- `start-purah.sh` читает `telegram.env` из XDG config каталога как буквальные `KEY=VALUE`, **не исполняя** содержимое. `setup_telegram.py` проверяет формат API hash и сообщает об автоматическом подхвате настроек.
- Внешние профили браузера, LSP-серверы, Telegram-сессия и API-ключи намеренно не создаются молча. Для выбранного Piper/Kokoro установщик использует существующие setup-скрипты.
- Добавлены регрессионные тесты на миграции, настройки и диагностику; `APP_VERSION` повышена, чтобы launcher распознал обновление.

## Обновление

```bash
./install.sh
./install.sh --check
./check.sh
```

Реальный запуск на Hyprland/Quickshell и работу с запущенным Firefox/Telegram нужно проверить на Linux пользователя.
