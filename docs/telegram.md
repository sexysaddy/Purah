# Фоновый Telegram-коннектор

PURAH может работать с Telegram напрямую через локальную пользовательскую
сессию Telethon. Окно Telegram Desktop для таких операций не открывается, а
фокус, мышь и клавиатура пользователя не используются. Опция остаётся
необязательной: без Telethon и локальной авторизации PURAH продолжает работать
с обычными файлами, shell и GUI-инструментами.

## Установка

```bash
python -m pip install -r requirements-telegram.txt
python setup_telegram.py
```

API ID и API hash выдаются в Telegram API Development Tools. Скрипт локально
создаёт `~/.config/purah/telegram.session` и `telegram.env` с правами `0600`.
Сессия содержит авторизацию пользователя, поэтому её нельзя коммитить,
передавать модели или класть в архив проекта. Подключи переменные окружения из
`telegram.env` до запуска PURAH; `start-purah.sh` должен импортировать этот
файл только из домашнего каталога пользователя.

## Безопасное разрешение получателя

Интеграция намеренно разделяет поиск и действие:

1. `resolve_recipient("Ивану Петрову")` возвращает кандидатов и короткоживущий
   непрозрачный `candidate_id`.
2. Точное единственное совпадение можно отправить этим ID.
3. Склонение имени, префикс канала или несколько совпадений имеют статус
   `confirmation_required`/`ambiguous`. PURAH должна показать кандидатов и
   попросить выбрать одного или подтвердить конкретный fuzzy-результат.
4. `send_message` принимает только выбранный ID. Поиск заново во время отправки
   не выполняется, поэтому имя не может внезапно разрешиться в другого человека.

После сетевого тайм-аута автоматический повтор запрещён: Telegram мог принять
   сообщение, пока клиент ждал ответ. Результат помечается `uncertain`, и PURAH
   предлагает проверить чат.

«Избранное» разрешается как специальный peer `me`, без поиска по похожим
   названиям. Последнее сообщение читается через `latest_message`; затем обычная
   модель PURAH может кратко пересказать полученный текст.

## Ограничения

Это API-доступ к аккаунту пользователя, а не Bot API. Доступ к закрытому каналу
возможен только если аккаунт уже состоит в нём. Коннектор читает текст последнего
сообщения, но не скачивает медиа и не пытается обходить приватность Telegram.
